## 🌐 How to Host It Live Online for Free (Before Tomorrow's Interview!)

You can host this portfolio live in less than 2 minutes so you can send the link to your interviewers:

### Option 1: Netlify Drop (Fastest — 30 Seconds, No Git Required!)
1. Open [https://app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
2. Drag and drop the `portfolio` folder directly into the browser window.
3. Netlify will give you a live URL instantly (e.g. `https://indumini-adarshya.netlify.app`)!

### Option 2: GitHub Pages (Recommended for Developers)
1. Go to [https://github.com/new](https://github.com/new) and create a repository named `indumini186.github.io` (or `portfolio`).
2. In PowerShell or Command Prompt inside the `portfolio` directory:
   ```bash
   cd "E:\Third year second sem all projects\Converter\portfolio"
   git init
   git add .
   git commit -m "Initial commit of Indumini developer portfolio"
   git branch -M main
   git remote add origin https://github.com/indumini186/indumini186.github.io.git
   git push -u origin main
   ```
3. Your portfolio is immediately live at:
   **`https://indumini186.github.io/`**

### Option 3: Vercel
1. Go to [https://vercel.com/new](https://vercel.com/new).
2. Import your GitHub repository or drag the folder.
3. Click **Deploy**. Done!
