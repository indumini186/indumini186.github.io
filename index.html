"How does your Multi-Converter Microservices monorepo work?"
"I designed it following the Backend-For-Frontend (BFF) architectural pattern. The single-page frontend talks only to a Node.js Express BFF gateway. The BFF gateway handles authentication, masks upstream service ports, and injects private X-API-Key headers server-to-server before calling upstream Java 17 Spring Boot microservices. MongoDB is integrated for audit logging and conversion histories, with built-in logic to trigger automated safety alerts for extreme temperatures. The entire stack is orchestrated cleanly with Docker Compose."
"Can you explain your Agentic AI Interview Coach project?"
"Instead of a simple chatbot prompt, I implemented a collaborative 4-agent workflow using LangGraph:
  • Resume Agent: Parses candidate profiles and identifies key skill gaps.
  • Question Agent: Queries a vector database (FAISS / ChromaDB) to retrieve role-tailored questions using RAG.
  • Evaluation Agent: Scores answers against 7 dimensions including the STAR method and provides constructive critiques.
  • Learning Coach Agent: Builds a personalized 7-day preparation roadmap.
It is deployed live on Streamlit Cloud with Groq low-latency inference."
